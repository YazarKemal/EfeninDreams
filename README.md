# EfeninDreams

Cute low-poly mining/adventure game built with Godot 4.

## Current milestone
- Godot project scaffold
- Playable 3D placeholder character
- Third-person camera
- Basic movement + jump
- Placeholder ground and test rock

## Controls
- WASD / Arrow keys: Move
- Mouse: Look
- Space: Jump
- Esc: Release mouse
